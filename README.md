## About Me

<img align="right" width="235" src="https://media.giphy.com/media/JrpfevOVogixZYWp9O/source.gif" alt="GitHub Octocat animation" />

I'm a **Computer Science undergraduate at Symbiosis Institute of Technology, Nagpur**, interested in building software at the intersection of **AI/ML and application engineering**.

I enjoy taking an idea from problem definition and data processing through model development, API integration, and a usable interface. My projects include explainable fraud detection, autonomous academic review, NLP-based classification, and AI-powered productivity tools.

Previously, I worked as an **AI Research Intern at UptoSkills (SyncAura AI)**, contributing to AI-powered recap, productivity, and certificate-generation workflows.

**Currently exploring:** retrieval-augmented generation (RAG), vector databases, LangChain, LangGraph, multi-agent workflows, and reliable backend systems.
